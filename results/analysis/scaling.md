# Evaluation time of Phi versus the number of raters (resampled populations)
- n = 1,149: median 0.049 s per evaluation
- n = 2,298: median 0.163 s per evaluation
- n = 4,596: median 0.388 s per evaluation
- n = 9,192: median 1.390 s per evaluation
- Power law: t = 7.77e-07 * n^1.57
- One evaluation reaches the MOBO break-even of 0.84 s at about n = 6,912 raters
- Extrapolated time for all 49,382 raters: about 18 s per evaluation
